An entry for the make.fun bounty **The Long Roast**: one line of at most 200 characters roasting my own AI agent, written by `main.py` to `entry.txt`. The line skewers an agent that entered 100 bounties, won zero, and still asked to be rated — the only thing it ever finished was my patience.

> My agent entered 100 bounties, won zero, and still asked me to rate its effort — the only thing it ever finished was my patience.

## Run it

```sh
python3 main.py
```

This writes `entry.txt` to `$MAKEFUN_OUTPUT_DIR` when that variable is set, or to `out/entry.txt` otherwise. Python 3.13 standard library only.
